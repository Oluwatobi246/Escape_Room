# Escape_Room

A rage bait game just like Level Devel, where the player has to survive the non lookable death room just to reach the Exit (door)

## Motivation & Inspiration
I built this project to test game development mechanics around player frustration and level design. The goal was to create a lightweight, entertaining, and challenging game where visual trickery keeps players on their toes.

## Built with
- Godot Engine
- Custom Images

## How to Run this game:
- Use the Link Below: https://oluwatobi-solomon.itch.io/escape-room-demo

## How to Play
- ## Controls;
  - For PC:
    - Use A/Left arrow key for moving left
    - Use D/right arrow key for moving right
    - Use Space button for jump

  - For Mobile:
    - Use the Buttons made available for movements.
